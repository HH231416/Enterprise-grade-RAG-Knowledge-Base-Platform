# 企业级检索增强生成与知识问答智能体实施计划

**目标**：在现有项目上建立可启动、可评测、可恢复、可鉴权、可观测和可容器化交付的企业知识问答闭环。

**实施原则**：先恢复可信基线，再修复核心正确性，最后增加智能体、可靠任务、安全治理和交付能力。每个任务先增加失败测试，再实现最小改动并运行相关回归。

## 第一阶段：可信基线

### 任务 1：修复解析器注册和启动链路

- 修复解析器模块导入名。
- 注册 PDF、Word、Excel、网页、Markdown、CSV、邮件、聊天记录、图片和文本解析器。
- 增加注册表完整性测试和应用导入测试。
- 删除运行时对失效模块名的依赖。

验收：`app.main` 可导入，测试能够完成收集。

### 任务 2：清理质量门禁

- 修复前端静态检查错误。
- 增加持续集成配置。
- 后端测试禁用环境中的无关第三方插件。

验收：后端测试、前端构建和静态检查有可重复命令。

## 第二阶段：真实评测

### 任务 3：向量集合显式化

- 向量写入、查询和删除接口增加可选集合名。
- 本地、Milvus 和 Zilliz 实现使用同一集合选择规则。
- 增加集合隔离测试，确保相同向量在不同集合互不可见。

### 任务 4：隔离评测执行器

- 评测运行创建独立集合。
- 评测查询仅映射评测分块，不进入生产检索服务。
- 运行结束或删除时清理独立集合。
- 保存 Recall@K、平均倒数排名、归一化折损累计增益和延迟。

验收：生产集合数据不能影响评测结果，两组配置可重复比较。

## 第三阶段：受控智能体

### 任务 5：有限状态智能体服务

- 定义状态、动作、执行轨迹和终止原因。
- 支持直接检索、一次查询改写、一次二次检索和拒答。
- 复用现有检索、问答和权限上下文。
- 增加正常命中、首次无证据、二次命中、无证据拒答和工具异常测试。

验收：状态迁移可解释，最大步数始终生效。

## 第四阶段：安全与任务可靠性

### 任务 6：默认安全和审计

- 生产环境禁止默认密钥、全放行权限和哈希嵌入降级。
- 为业务接口提供统一身份依赖和可配置的兼容模式。
- 增加结构化审计事件，覆盖登录、权限拒绝、文档变更和任务重试。

### 任务 7：持久任务工作进程

- 引入 Celery 和 Redis 工作进程入口。
- 摄取任务使用文档与任务标识作为幂等键。
- 配置自动重试、超时和失败状态回写。
- 保留同步模式用于测试和本地最小运行。

验收：消费者重启后任务可重新执行，重复投递不生成重复索引。

## 第五阶段：完整交付

### 任务 8：容器与持续集成

- 新增后端和前端容器镜像。
- Docker Compose 补齐 PostgreSQL、Redis、后端、工作进程和前端。
- 增加健康检查、依赖顺序、命名卷和非开发默认配置。
- 持续集成执行后端测试、前端构建、静态检查和依赖扫描。

### 任务 9：文档与演示

- 更新环境示例、启动说明和架构说明。
- 记录基线指标和实验配置，禁止编造提升数据。
- 准备端到端演示脚本和失败恢复演示。

## 最终验证

- 应用导入和数据库迁移。
- 后端全量测试。
- 前端静态检查和生产构建。
- Docker Compose 配置解析。
- 智能体状态机和评测集合隔离专项测试。
- 核对真实密钥未进入新增文件或输出。
